# asutp-remote-stand

Учебный стенд инженера автоматизации: контроллеры, КИП, шины, привод, верхний уровень.

Архитектура: прибор → модуль ввода-вывода → контроллер → исполнительный механизм; сверху SCADA.
Логика живёт в контроллере (CODESYS). Linux-узел служебный: брокер MQTT, эмуляторы, узел CAN.

## Структура

- `python-basics/` — уроки 1–6 до курса
- `pi3/etc/` — копии системных конфигов Linux-узла
- `stageN/lessonNN/` — материалы занятий
- `HONESTY.md` — карта компетенций по стеку курса и журнал занятий: что сделано руками на работе и на стенде, что видел рядом, чего не касался

## Стенд

| Узел | Роль |
|---|---|
| Raspberry Pi 3B (`pi3`) | Linux-узел: брокер MQTT, сервисы, эмуляторы, узел CANopen |
| Ubuntu 24.04 в VM (`u2404`) | Рабочее место, диагностика, мастер CAN |
| Windows в VM (`cds`) | CODESYS, Control Win, SCADA |
| Windows 11, хост | Репозиторий, инструменты наладчика |

# asutp-remote-stand

Учебно-рабочий стенд по направлению АСУ ТП 

## Зачем

- настройка и параметризация контроллеров, в том числе удалённая
- создание и доработка скриптов автоматизации, углубление Python
- RS-485, Ethernet, Modbus RTU/TCP, MQTT, OPC UA
- TCP/IP, IP-адресация, маршрутизация, диагностика сетевых соединений
- Linux Ubuntu / Raspberry Pi OS, работа в командной строке

## Состав

- Raspberry Pi 3B — контроллер
- рабочее место: Ubuntu 24.04 в VM

## Стек

Linux (Debian/Ubuntu) · Python · MQTT · Modbus RTU/TCP · RS-485 · OPC UA

## Структура репозитория

- `HONESTY.md` — карта компетенций и что подтверждается практикой
- `python-basics/` — уроки Python 1–6, пройдены до курса

## Структура курса

Архитектура стенда: прибор → контроллер → частотник; Linux сверху читает, публикует, хранит и показывает.

1. Linux-узел с нуля (занятия 1–6) — закрыт
2. MQTT (7–12)
3. Python как инструмент инженера (13–18)
4. Modbus и RS-485 (19–26)
5. ПЛК на CODESYS (27–41)
6. Логика на контроллере (42–46)
7. Привод (47–53)
8. Хранение и анализ (54–58)
9. Здания и Wiren Board (59–64)
10. Витрина и итоги (65–66)

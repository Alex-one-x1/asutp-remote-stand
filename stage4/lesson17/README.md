# Занятие 17 — приборы по одному и разведение адресов

Модуль: релейный, 4 канала, плата bestep, MAX485, питание 12 В (допуск 7–24 В по карточке товара).
Заводские: адрес 255, 9600 8N1. Инструмент: QModMaster на Windows, COM5.

## Топология шины (решение занятия 16)

Конвертер — XY-MD02 — релейный модуль, шлейфом; терминаторы сняты, см. «Покой линии.

## Модуль один на шине

| Запрос | Результат | Смысл |
|---|---|---|
| 01, coils 0, кол-во 1 и 8, слейв 255 | ответ `FF 01 01 00 60 60` | реле выключены |
| 01, coils 0, кол-во 2 и 4, слейв 255 | таймаут | прошивка читает coils только по 1 или 8; биты 4–7 — нули |
| 03, рег. 0x4000, слейв 255 | таймаут | регистр адреса из описания LC Technology не подходит |
| 03, рег. 0x0000, слейв 255 | таймаут | |
| 03, рег. 0x03E8, слейв 255 | ответ `FF 03 02 00 03 D1 91` = 3 | скорость; по ряду 0=1200…4=19200 это 9600 — совпадает с текущей, не доказано |
| 03, рег. 0x0000, слейв 0 (широковещательный) | ответ `00 03 02 00 FF C5 C4` = 255 | регистр адреса найден; читается только широковещательно — отступление от стандарта, допустимо только с прибором один на шине |
| 16, рег. 0x0000 = 2, слейв 0 | запрос `00 10 00 00 00 01 02 00 02 2A 01` (совпал с инструкцией), QModMaster: Invalid CRC | прибор отвечает эхом всей команды вместо стандартных 8 байт; программа режет ответ на 8 байт — запись проверяется чтением |
| 03, рег. 0x0000, слейв 0 | ответ `00 03 02 00 02 04 45` = 2 | адрес записан |
| 01, coils 0, слейв 2 | ответ `02 01 01 00 51 CC` | модуль на новом адресе |
| 01, coils 0, слейв 255 | таймаут | старый адрес не отвечает |
| 01, coils 0, слейв 2, после выключения питания | ответ | адрес сохранён в энергонезависимой памяти |

## Карта модуля (проверено на приборе)

| В кадре | Классический номер | Функция | Смысл | Прочитано |
|---|---|---|---|---|
| 0x0000 (coils) | 00001 | 01, кол-во 1 или 8 | реле 1…4, биты 4–7 нули | 0 |
| 0x0000 (holding) | 40001 | 03, только слейв 0 | адрес модуля | 255 |
| 0x03E8 (holding) | 41001 | 03 | код скорости | 3 (вероятно 9600) |

## Покой линии

| Состояние | A − B в покое |
|---|---|
| Без терминаторов | 4,37 В |
| Терминаторы 120 Ом на концах, A–B без питания 59 Ом | 0,12 В — ниже порога 200 мВ |
| Терминаторы сняты | 4,377 В |

Связь с терминаторами при покое 0,12 В: слейв 2, 52 запроса, 0 ошибок — на столе помех нет, неопределённый покой не проявился.
Решение: на стенде терминаторы не ставим — линия короткая, 9600, отражений нет, покой полный. На объекте терминаторы и смещение считаются вместе.

Смещение конвертера и модуля (килоомы) рассчитано на линию без терминаторов: делитель с нагрузкой 60 Ом опускает покой в неопределённую зону. Терминаторы и смещение считаются вместе: Uпит × Rтерм / (Rверх + Rниз + Rтерм) ≥ 200 мВ.

## Сканер шины

`scan_bus.py` на pi3, конвертер переставлен в USB малинки (`/dev/ttyUSB0`). Аргументы: порт, скорости, диапазон адресов, таймаут, `-v`. Журнал: консоль INFO, файл `scan_bus.log` DEBUG.
Пробы по очереди: 01 coil 0, 03 holding 0, 04 input 0; любой ответ, включая исключение, — прибор есть.

| Адрес | Результат |
|---|---|
| 1 | функция 03: исключение 02 (01 — тишина) |
| 2 | функция 01: данные 0 |
| 3–5 | тишина на все три функции |

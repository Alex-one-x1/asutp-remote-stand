# Modbus — шпаргалка

## Структура кадра RTU

Два разных адреса:
- **адрес устройства** (слейв) — первый байт кадра, кому запрос: 1–247, 0 — широковещательный;
- **адрес регистра** — номер ячейки внутри устройства, в hex, как в паспорте.

Числа в кадре — старший байт первым, кроме CRC: у него младший первым.

| Кадр | Состав |
|---|---|
| Чтение, запрос (01, 02, 03, 04) | адрес устройства · функция · адрес первого регистра (2 байта) · количество (2 байта) · CRC (2 байта) |
| Чтение, ответ | адрес устройства · функция · число байт данных · данные · CRC |
| Исключение | адрес устройства · функция + 0x80 · код исключения · CRC |
| Запись одного, запрос (05, 06) | адрес устройства · функция · адрес регистра (2) · значение (2) · CRC |
| Запись одного, ответ | эхо запроса |
| Запись нескольких, запрос (15, 16) | адрес устройства · функция · адрес первого регистра (2) · количество (2) · число байт · данные · CRC |
| Запись нескольких, ответ | адрес устройства · функция · адрес первого регистра (2) · количество (2) · CRC |

Данные регистров (03, 04): 2 байта на регистр, старший первым.
Данные битов (01, 02): упакованы в байты, младший бит первого байта — первый запрошенный бит.

## Области данных

| Префикс | Область | Перевод | Смысл | Ячейка | Доступ |
|---|---|---|---|---|---|
| 0 | Coils | дискретные выходы («катушки») | команда вкл/выкл: реле, клапан | 1 бит | чтение и запись |
| 1 | Discrete inputs | дискретные входы | состояние есть/нет: кнопка, концевик | 1 бит | только чтение |
| 3 | Input registers | входные регистры | измерение: температура, ток | 16 бит | только чтение |
| 4 | Holding registers | регистры хранения | настройка, уставка: адрес, скорость | 16 бит | чтение и запись |

## Функции

| Код | Область | Действие |
|---|---|---|
| 01 | Coils | чтение |
| 05 | Coils | запись одного |
| 15 | Coils | запись нескольких |
| 02 | Discrete inputs | чтение |
| 04 | Input registers | чтение |
| 03 | Holding registers | чтение |
| 06 | Holding registers | запись одного |
| 16 | Holding registers | запись нескольких |

Область выбирает код функции. В кадре адрес — номер ячейки с нуля внутри области, без префикса.
Адрес 0 есть в каждой области отдельно: это четыре разные ячейки.

## Классический номер ↔ адрес в кадре

    классический номер = префикс × 10000 + адрес в кадре + 1
    адрес в кадре      = классический номер − префикс × 10000 − 1

| Паспорт | Функция чтения | Адрес в кадре |
|---|---|---|
| 30001 | 04 | 0 = 0x0000 |
| 40001 | 03 | 0 = 0x0000 |
| 40258 | 03 | 257 = 0x0101 |

Первый вопрос к паспорту: это адрес в кадре (обычно hex с указанием функции) или классический номер (3xxxx, 4xxxx)?
Соглашение репозитория: основная запись — hex-адрес в кадре и код функции, классический номер в скобках для сверки.

## Запись чисел

| Запись | Система | Пример |
|---|---|---|
| `0x` | шестнадцатеричная | 0x0010 = 16, 0x000A = 10, 0x0101 = 257 |
| `0b` | двоичная | 0b1010 = 10 |
| без префикса | десятичная | 16 |

Hex: A=10 … F=15; разряды справа 1, 16, 256, 4096. Одна hex-цифра = 4 бита, байт = 2 цифры, регистр = 4 цифры.

## Реакция прибора на запрос

| Что пришло | Смысл |
|---|---|
| ответ с данными | норма |
| исключение 01 | функция не поддерживается — такой области у прибора нет |
| исключение 02 | адреса нет в карте |
| тишина (таймаут) | кадр не принят: адрес, скорость, CRC, питание, A/B |

# Занятие 19 — форматы и отказы

Часть 1 — прослушка шины, исключения и тишина, порядок поиска молчащего прибора.
Часть 2 — 32-битные значения, порядок слов и байт: позже.

Шина: XY-MD02 (слейв 1) — релейный модуль (слейв 2), 9600 8N1, без терминаторов.
Мастер: `poll_stand.py` на pi3, конвертер CH340 — `/dev/serial/by-id/usb-1a86_USB_Serial-if00-port0`.
Сниффер: `sniff_bus.py` на pi3, второй конвертер FTDI FT232R параллельно шине, только приём — `/dev/serial/by-id/usb-FTDI_FT232R_USB_UART_A5069RR4-if00-port0`.

## Исключения и тишина

| Код | Название | Когда |
|---|---|---|
| 01 | Illegal function | функция не поддерживается |
| 02 | Illegal data address | адреса нет в карте |
| 03 | Illegal data value | недопустимое значение или количество |
| 04 | Slave device failure | прибор не смог выполнить |

Исключение — связь работает, прибор отказал осознанно. Тишина — кадр не принят.

## Сниффер

Порты — по `/dev/serial/by-id/`: номера ttyUSB раздаются в порядке обнаружения и после перезагрузки поменялись местами.
Кадры разделяются по паузе между байтами, отмеренной в программе по `time.monotonic()`; CRC пересчитывается. В скрипте нет записи в порт — вторым мастером он стать не может.
latency_timer FTDI — 16 мс (по умолчанию, проверено 07.10): кадры делятся корректно. Склейку в первой версии давал межбайтовый таймаут pyserial, а не таймер FTDI.
При открытии порта сниффер получал байты, накопленные до запуска, — добавлен сброс входного буфера после открытия.
Межбайтовый таймаут pyserial (`inter_byte_timeout`) для миллисекундных пауз непригоден: первая версия сниффера склеивала весь цикл опроса в один кадр с ошибкой CRC.

## Цикл опроса на линии (между началами кадров, точность ≈ 1 мс)

| Интервал | мс | Состав |
|---|---|---|
| запрос датчику → ответ | 12 | запрос 8 байт ≈ 8,3 + реакция датчика ≈ 3,7 |
| ответ датчика → запрос модулю | 34 | ответ 9 байт ≈ 9,4 + пауза 20 + накладные ≈ 4,6 |
| запрос модулю → ответ | 18,8 | 8,3 + реакция модуля ≈ 10,5 |
| ответ модуля → запрос модулю | 14 | ответ 6 байт ≈ 6,2 + пауза ≈ 7,8 |

## Открытый вопрос занятия 18

Опрос без паузы (`--gap 0`): сниффер видит запрос модулю `02 02 00 00 00 08 79 FF` целым, ответа нет.
Линия не испорчена: столкновение исказило бы байты и у сниффера.
Пауза «ответ датчика → запрос модулю» ≈ 7,6 мс — модуль молчит; «ответ модуля → запрос модулю» ≈ 7,8 мс — отвечает.
Вывод: модуль после чужого кадра не готов принять следующий через 3,5 символа — отступление прошивки модуля от стандарта. Решение — пауза между приборами 20 мс (занятие 18).

## Порядок поиска молчащего прибора

1. Контрольный запрос: проверенные на этом приборе функция и адрес.
2. Питание прибора.
3. Адрес, в том числе конфликт двух одинаковых.
4. Параметры линии: скорость, чётность, стоп-биты; несовпадение даёт тишину.
5. Полярность A/B.
6. Терминаторы, смещение, топология.
7. Таймаут и пауза между запросами.
8. Второй мастер на линии.
9. Прослушка шины вторым портом или анализатором.

## Карта DDS6619 (по паспорту, не проверено)

Шапка: чтение 03 и 04, запись 16 (0x10), широковещательный адрес 0; по умолчанию 9600 8N1, адрес 1.

Измерения — input registers, функция 04:

| В кадре | Классический | Величина | Формат | Регистров | Масштаб |
|---|---|---|---|---|---|
| 0x0000 | 30001 | напряжение | Int | 1 | ×0,1 В |
| 0x0003 | 30004 | ток | Int | 1 | ×0,1 А |
| 0x0008 | 30009 | активная мощность | Int | 1 | ×1 Вт |
| 0x0014 | 30021 | коэффициент мощности | Int | 1 | ×0,001 |
| 0x001A | 30027 | частота | Int | 1 | ×0,01 Гц |
| 0x001D | 30030 | активная энергия, всего | long | 2 | ×0,01 кВт·ч |
| 0x0027 | 30040 | активная энергия, прямая | long | 2 | ×0,01 кВт·ч |
| 0x0031 | 30050 | активная энергия, обратная | long | 2 | ×0,01 кВт·ч |
| 0x003B | 30060 | реактивная энергия | long | 2 | ×0,01 квар·ч |

Настройки — holding registers, функция 03 / 16, формат float (2 регистра):

| В кадре | Классический | Параметр |
|---|---|---|
| 0x0000 | 40001 | скорость: 1200, 2400, 4800, 9600 |
| 0x0002 | 40003 | чётность: 0 — even, 1 — odd, 2 — none |
| 0x0008 | 40009 | адрес 1–247 |

Проверить на приборе: Int со знаком или без; порядок слов в long; ответ функции 03 по адресам измерений.

## Примеры из паспорта DDS6619

CRC всех примеров пересчитаны — совпадают.

| Что | Запрос | Ответ | Данные | Значение |
|---|---|---|---|---|
| напряжение, слейв 1 | `01 04 00 00 00 02 71 CB` (CRC посчитан) | в паспорте нет | | |
| адрес | `00 03 00 08 00 02 44 18` | `00 03 04 3F 80 00 00 E7 0F` | float 3F800000 | 1,0 |
| скорость | `00 03 00 00 00 02 C5 DA` | `00 03 04 46 16 00 00 1E 7F` | float 46160000 | 9600,0 |
| чётность | `00 03 00 02 00 02 64 1A` | `00 03 04 40 00 00 00 FF 33` | float 40000000 | 2,0 — none |

float: знак 1 бит, порядок 8 бит (смещение 127), мантисса 23 бита с подразумеваемой единицей. Порядок слов в примерах — старшее слово первым.
Смена адреса — запись float (2,0 = `40 00 00 00`) функцией 16 в 0x0008–0x0009, не целого.

## Порядок слов

Байты внутри регистра — всегда старший первым (стандарт). Порядок регистров у 32-битных значений стандарт не задаёт.
Варианты: ABCD (старшее слово первым), CDAB (младшее первым) — основные; BADC, DCBA — редкость.

| Значение | ABCD | Прочитано как ABCD при CDAB |
|---|---|---|
| float 9600,0 | 4616 0000 | 2,5·10⁻⁴¹ |
| long 500 (5,00 кВт·ч) | 0000 01F4 | 32 768 000 (327 680 кВт·ч) |

Определение на объекте: известное значение; для малого long нулевой регистр — старшее слово.
DDS6619: float — ABCD по паспорту; long — проверить по 0x001D–0x001E при включении.

## Знаковые значения

16 бит: без знака 0…65 535, со знаком −32 768…32 767 (дополнительный код: значение ≥ 0x8000 минус 65 536).
Признак ошибки толкования — малая величина показывает ≈ 65 535.

| Байты | Без знака | Со знаком |
|---|---|---|
| FF FB (×0,1 °C) | 6553,1 | −0,5 °C |
| FF 6A (Вт) | 65 386 | −150 Вт |
| 80 00 (заглушка XY-MD02) | 32 768 | −32 768 |

DDS6619: Int без указания знака; мощность при обратном потоке — не проверить на стенде (нет источника в сеть). Есть отдельный регистр обратной энергии 0x0031.

## Отложено

Живая проверка счётчика DDS6619 — после сборки щитка: бокс, автомат, УЗО тип A, розетка, клеммы под крышкой. Перед первым включением — проверка схемы по правилам безопасности стенда.

Порядок при включении:
1. Счётчик один на шине: заводской адрес 1 совпадает с XY-MD02.
2. Чтение адреса широковещательно: `00 03 00 08 00 02 44 18`, ожидается float 1,0.
3. Смена адреса на 3 — запись float 3,0 (`40 40 00 00`) функцией 16 в 0x0008–0x0009, проверка чтением и выключением питания.
4. Проверить: функция 04 по адресам измерений; ответ функции 03 по тем же адресам; Int со знаком или без; порядок слов long по 0x001D–0x001E.
5. Подключить к общей шине, добавить в опрос и в лист проверки сигналов.

# Занятие 18 — чтение и запись

Шина: конвертер (Windows, COM5) — XY-MD02 (слейв 1) — релейный модуль (слейв 2), 9600 8N1, без терминаторов.

## Реле, функции 05 и 01

| Запрос | Ответ | Смысл |
|---|---|---|
| 05, coil 0 = FF00 | эхо `02 05 00 00 FF 00 8C 09` | реле 1 включено, щелчок, светодиод |
| 05, coil 0 = 0000 | эхо `02 05 00 00 00 00 CD F9` | реле 1 выключено |
| 01, coil 0, кол-во 8, реле 1 вкл. | `02 01 01 01 90 0C` | байт 01 |
| 01, coil 0, кол-во 8, все вкл. | байт 0F | биты 4–7 нули |

## Вход IN1, функция 02

Вход развязан оптроном: GND входов не связан с минусом питания модуля; без внешнего источника на IN1 ≈ 0 В — вход ждёт внешнее напряжение.
Источник: SG-002, выход напряжения AVo → IN1, GND → GND входов.

| Запрос | Ответ | Смысл |
|---|---|---|
| 02, вход 0, кол-во 8, IN1 = 0 | `02 02 01 00 A1 CC` | байт 00 |
| 02, вход 0, кол-во 8, IN1 = 1 | `02 02 01 01 60 0C` | байт 01 |
| 02, кол-во 4 | таймаут | входы читаются только по 1 или 8 |

Порог: включение между 2,6 и 2,7 В, выключение между 2,5 и 2,6 В, гистерезис ≈ 0,1 В. В карточке гарантировано от 3,3 В — проектировать по нему.

## Пауза между приборами

В опросе подряд «датчик → модуль» модуль молчал на каждом цикле; по одному отвечал на все запросы.
Проверка паузой между ответом датчика и запросом модулю: 0 мс (минимум библиотеки ≈ 4 мс) — тишина; 10, 20, 50, 100 мс — ответ.
Решение: пауза перед запросом к другому прибору, `--gap`, по умолчанию 20 мс. На объекте — настройка мастера «пауза между запросами».
Открыто: кто держит линию — датчик после ответа или модуль после чужого кадра. Проверить анализатором на занятии 19.

## Периодический опрос

`poll_stand.py` на pi3: TS1, HS1, SW1, RL1–RL4 раз в секунду, пауза 20 мс между приборами, журнал в консоль и `poll_stand.log`.

| Режим | Смещение к циклу 29 |
|---|---|
| наивный `sleep(period)` | +3,214 с (прогноз 3,2 с) |
| фиксированное расписание от `time.monotonic()` | +0,000 с |

Отказ датчика (снято питание): модуль опрашивается без перерыва; цикл удлиняется на ≈ 0,17 с (таймаут 0,2 с вместо ответа ≈ 30 мс), в период укладывается.
После включения датчик несколько циклов отвечает заглушками: 0/0 и 0x8000 (−3276,8 °C / 3276,8 %) — кадр верный, значение нет. Добавлена проверка правдоподобия: вне диапазона или 0/0 — «НЕДОСТОВЕРНО».

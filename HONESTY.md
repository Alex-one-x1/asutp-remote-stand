## Что теперь могу сказать честно

### Занятие 1 — чистая установка контроллера, 11.09.2026

- записал Raspberry Pi OS Lite Bookworm 64-bit на карту через Imager;
- в преднастройке задал: имя хоста, пользователя, часовой пояс, раскладку, SSH по ключу, Wi-Fi;
- нашёл на VM ключ с чужим комментарием, проверил его, сгенерировал новый своей парой;
- подключил Raspberry Pi3b кабелем к роутеру; Wi-Fi тоже поднялся, оба интерфейса получили адреса по DHCP;
- зашёл с рабочей VM Ubuntu 24.04 по SSH без пароля.

### Занятие 2 — сети: адресация, маршруты, 11.09.2026

- перевёл eth0 RPi3b на статику через nmcli: адрес 192.168.1.111/24, шлюз, DNS, метод manual;
- проверил, что статика пережила перезагрузку и маршрут стал proto static;
- отключил кабель Ethernet при "живом" Wi-Fi, посмотрел, как снимаются маршруты, подключил обратно, записи и подключение восстановилось;
- на VM нашёл конфликт двух конфигов netplan: свой 01-netcfg.yaml перекрывался 50-cloud-init.yaml с dhcp4: true;
- отключил cloud-init от управления сетью, удалил его конфиг, заменил устаревший gateway4 на routes, закрыл права на файл;
- проверил через netplan try с откатом по таймауту, применил, убедился в работоспособности после перезагрузки.
